# Ralph progress: Automatos Play pilot (PRD-001)

## Patterns
<!-- Reusable patterns for later sessions. Keep this short and current. -->
- Nothing runs locally. Pin dependency versions with `npm view <pkg> version` and edit package.json by hand. CI is the gate.
- The backend is reached only through app/api/* routes; the browser uses lib/client/api.ts.
- The mascot files in public/auto/ are git-ignored and absent in CI: always degrade to the placeholder.
- Vitest globals are OFF: import describe/it/expect/vi from "vitest" in every test. tests/setup.ts loads jest-dom matchers and RTL cleanup. Tests live in tests/ (or next to code) as *.test.ts(x); the @/* alias maps to the repo root.
- vitest 5 needs vite as a peer: vite is pinned in devDependencies. Keep vite, vitest and @vitejs/plugin-react moving together.
- ESLint is flat config (eslint.config.mjs) with FlatCompat over next/core-web-vitals + next/typescript; `npm run lint` is `eslint .`. docs/, skills/, scripts/, public/ are ignored.
- next-env.d.ts is committed (classic two references) so `tsc --noEmit` works before any `next build`.
