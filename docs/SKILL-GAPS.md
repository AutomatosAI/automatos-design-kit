# Skill gaps

Where `skills/build-automatos-interface/` or the mocks were wrong, missing or unclear during the build (the pilot, US-001 to US-015; Looks, L-001 to L-008; the main pages, P-001 to P-011), and what was done. The core wins: the skill is fixed to match it. The mocks are Gerard's design file and are not edited here: where Play differs from them, the row says how, and it is his call.

**Count:** 44 skill gaps (all fixed in the skill; P-003 to P-011 are PRD-003 wave 3, B-001 on are wave 4), 9 mock gaps, 1 PRD/repo note, and (PRD-002, Looks) 6 design gaps. Three core changes are written up as open questions in the PRD (9 and 10) or flagged (the `agent-info` nesting); none was made. Wave 3's core limits are PRD-003's open questions 1 to 5; again, no core change.
